# mobile-sales-dashboard
This Power BI dashboard visualizes mobile sales performance across various Indian cities. It includes key performance metrics such as Total Sales, Quantity, Transactions, Customer Ratings, and Payment Method insights.
## 🚀 Features

- Total Sales: ₹62M
- Total Quantity: 2K units
- Average Sales per Transaction: ₹39K
- Filters by Month
- Sales by City (Map)
- Top Mobile Models Sold
- Transactions by Payment Method
- Ratings Breakdown
- Day-wise Sales Trend

## 🛠 Tools Used

- Power BI Desktop
- Microsoft Excel (Data Source)
- Map Visuals, Pie Chart, Bar Charts, Line Graphs
